# 搶答鈴（buzzer，測試資源包）

手機變成搶答鈴。主持人口頭出題（或用投影片），誰先按到全場都看得到。

## 怎麼玩

- **學員**：從活動的「開始遊戲」進來，畫面是一顆大按鈕。主持人開放後按鈕變紅、亮起來，馬上按。有人搶到後，每支手機都會顯示是哪一隊的誰。
- **主持人（工作人員）**：唸完題目按「開放搶答」。有人按了以後畫面顯示搶到的人（和後面幾位的順序）。
  - 「答對」：那一隊加分，回到等待，準備下一題。
  - 「答錯」：那一隊這題不能再搶；如果還有其他隊的人也按了，直接換下一位，沒有的話重新開放給其他隊搶。
  - 「這題作廢」：回到等待，不加不扣。
- **投影**：主持人畫面按「📺 投影畫面」，顯示「搶答！」、搶到的小隊和名字、各隊分數。

## 設定

| 設定 | 說明 |
| --- | --- |
| 答對加幾分 | 預設 10 |
| 答錯扣幾分 | 預設 0（不扣）。怕大家亂按可以設 5。 |
| 按開放後幾秒按鈕才亮 | 預設 5 秒，留時間讓每支手機收到。 |

## 怎麼算誰最快

- 每支手機記「按鈕亮起來到按下去」花了幾毫秒，最短的贏。晚一點收到的手機，按鈕晚一點亮，但反應時間照自己的算，不吃虧。
- 第一個人按了以後，主持人的手機會再等 1.5 秒收齊同時按的人，再決定是誰。
- 各隊分數可以在主持人畫面手動加減，結束時按「送進團隊計分」（一隊一筆，重送會更新）。

## 建議的玩法

- **每隊派代表搶答**（一隊一兩支手機）最順：手機少，每支都很快收到，按鈕幾乎同時亮，秒數設 3 就夠。
- **全場 100 人一起搶**也可以，但人越多每支手機收到「開放」越慢（100 人壓力測試：一半的手機 5 秒內、九成 10 秒內）。這時把秒數設 10，不然比較晚收到的手機按鈕還沒亮就被別人搶走了。

## 注意

- 按鈴走即時同步（不是送出收件），所以很快，但斷網時按的不會補送（搶答本來就要即時）。
- 主持人換手機或重新整理，分數和進度會自動找回來。
