# 搶答鈴（buzzer，測試資源包）

手機變成搶答鈴。主持人口頭出題（或用投影片），誰先按到全場都看得到。

## 怎麼玩

- **主持人（工作人員）**：
  1. 按「下一題」：大家的手機按鈕變成橘色「預備」。
  2. 唸題目。唸完按「開放搶答！」，同時喊「搶答」（投影畫面也會閃「搶答！」）。
  3. 畫面顯示搶到的人（和後面幾位的順序）。
     - 「答對」：那一隊加分，回到等待。
     - 「答錯」：那一隊這題不能再搶；如果還有其他隊的人也按了，直接換下一位，沒有的話重新開放給其他隊搶。
     - 「這題作廢」：回到等待，不加不扣。
- **學員**：按鈕變成「預備」後，聽主持人喊「搶答」再按。每題只能按一次。**太早按（主持人還沒開放）算偷跑，這一題不能搶。**
- **投影**：主持人畫面按「📺 投影畫面」，顯示「聽題目…」「搶答！」、搶到的小隊和名字、各隊分數。

## 設定

| 設定 | 說明 |
| --- | --- |
| 答對加幾分 | 預設 10 |
| 答錯扣幾分 | 預設 0（不扣）。怕大家亂按可以設 5。 |

## 怎麼算誰最快

- 手機記下「按下去那一刻的伺服器時間」送給主持人，主持人開放之後最早按的人贏。比的是按下去的時間，不是誰的網路快。
- 全場人很多時，手機收到「開放」（按鈕變紅）可能會慢幾秒，所以**以主持人喊的、投影閃的為準**，按鈕還是橘色「預備」也可以按，一樣算。
- 第一個人按了以後，主持人的手機會再等 1.5 秒收齊同時按的人，再決定是誰。
- 每支手機和伺服器對時大約有 0.1～0.3 秒的誤差，差距很小的時候可能不是絕對公平；營隊遊戲夠用，正式比賽請用實體搶答鈴。
- 各隊分數可以在主持人畫面手動加減，結束時按「送進團隊計分」（一隊一筆，重送會更新）。

## 注意

- 按鈴走即時同步（不是送出收件），所以很快，但斷網時按的不會補送（搶答本來就要即時）。
- 主持人換手機或重新整理，分數和進度會自動找回來。
- 主持人要先按「下一題」等幾秒（唸題目的時間）再開放，讓每支手機都進入預備；100 人同時玩時，手機大約 10 秒內都會收到。
