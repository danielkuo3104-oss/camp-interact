# 即時投票（vote，測試資源包）

現場即時投票。晚會票選、選宵夜、課程回饋、小隊表決都能用。不計分。

## 怎麼玩

- **學員**：從活動的「開始遊戲」進來，主持人開始投票後手機出現問題和選項，按一個就投了。投票結束前可以改（最後一次算）。結束後手機顯示各選項的票數和百分比。
- **主持人（工作人員）**：在「準備好的題目」按「開始投票」，或在「當場出題」打問題和選項（一行一個）再開始。投票中即時看票數，按「結束投票並公布結果」後，每支手機都看到結果。可以「同一題重投」。
- **投影**：主持人畫面按「📺 投影畫面」，長條圖會跟著票數即時長高，結束時最高票的選項會亮起來。

## 設定

| 設定 | 說明 |
| --- | --- |
| 預先準備的題目 | 一行一題：`問題|選項1|選項2|…`，選項 2～6 個。可以不填，現場再出題。 |
| 匿名 | 1（預設）：主持人只看得到票數。0：主持人投票中看得到誰投了什麼（結束後也只顯示票數）。 |

## 注意

- 學員投票時看不到別人投什麼（避免跟風），結束後才看得到結果；投影畫面是即時的，不想讓大家看到可以先不開投影。
- 每人一票，改投會蓋掉前一次。
- 斷網時投的票會先存在手機，連上後補送；主持人已經結束投票的話就不會算進去。
- 主持人換手機或重新整理，進行中的投票會自動找回來。
