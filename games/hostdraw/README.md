# 現場抽獎（測試用資源包）

主持人（工作人員）輸入獎項、人數，按「抽獎」。打開這個遊戲的人都在同一個「房間」裡：大家手機和投影上看到所有人的名字，燈號跑一陣子後同時停在被抽到的人身上，被抽到的名字亮起來，中獎的人手機放中獎動畫。

## 學員怎麼玩

活動卡片按「🎮 開始遊戲」，畫面開著就算進房間（上面寫「● 在房間裡（N 人）」，自己的名字有藍框）。不用按任何東西，等主持人抽。

- 抽獎時：畫面上方顯示獎項和倒數，名單上的名字一個一個亮（跑燈），越來越慢。
- 揭曉：被抽到的名字變金色發光，下面列出得主。自己被抽到的話全畫面彩帶「🎉 你抽中了！」。
- 下面有「抽獎紀錄」，自己中的會標「🎉 我」。重開畫面不會重播動畫。

切到別的 App 太久（75 秒）會離開房間，就不會被抽到；回來會自動再進房間。

## 主持人

工作人員端活動卡片按「🎯 關主登入」：

- **抽獎**：填獎項（可以從常用獎項選）、幾位，「抽過的人不再抽」預設打勾，按「🎲 抽獎」。只會抽**現在在房間裡**的人。
- **房間裡 N 人**：誰在房間裡（照小隊排）。
- **📽 投影畫面**：用工作人員登入的電腦打開，大字名單、跑燈（有滴滴聲）、揭曉動畫和得主名單；下方工具列也可以直接抽獎、全螢幕、關聲音。
- **抽獎紀錄**：每次抽了誰，和「📶 幾支手機收到、從按抽獎到收到花幾秒、揭曉前收到幾支」。

## 設定欄位

| 欄位 | 說明 |
| --- | --- |
| 名稱 | 預設「現場抽獎」 |
| 按抽獎後幾秒揭曉 | 預設 10。這段時間是跑燈，也是留給大家手機收到的時間；100 人建議 10 秒以上 |
| 幾秒沒動靜算離開房間 | 預設 75 |
| 常用獎項 | 一行一個，主持人可以直接選 |

## 即時性怎麼做到的

中獎的人在按下「抽獎」時就決定好，連同「幾點揭曉」一起送出；每支手機照伺服器時間跑燈、同一刻揭曉。所以**只要在揭曉前收到，大家（包括投影）是同一刻亮起來**；比較晚收到的手機會直接顯示結果。

每支手機每 5 秒同步一次（名單和抽獎同一次拿），人多時伺服器會叫大家放慢（整個營隊每秒約 12 次），100 人時大約 8 秒一次。實際花多久看主持人畫面的「📶」，或用 `test/loadtest-casino.js draw` 測。

## 資料怎麼存

- 房間：同步頻道 `room:活動範圍`，每人一格。學員寫 `{ kind: 'here', sq }`（每 25 秒更新），主持人寫 `{ kind: 'draws', draws: [最近 8 次] }`；抽獎只認工作人員寫的，名字由伺服器依登入填。
- 每次抽獎也送一份到 `w-room:活動範圍`（遊戲收件），快取被清掉時主持人畫面會補回。
- 手機回報：同步頻道 `in-room:活動範圍`。
- 測試模式結束歸零時，抽獎紀錄一起清掉。

## 已知限制（測試版）

- 同一個人開兩個分頁只算一個人。
- 工作人員「🎮 開始遊戲」試玩會進正式的房間（測試時方便湊人數），也可能被抽到。
- 沒有領獎紀錄，只有抽獎紀錄。
