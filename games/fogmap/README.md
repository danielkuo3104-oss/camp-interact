# 霧之校園（測試用）

定向越野加集章的示範遊戲，用來測試遊戲資源包的整套流程，不是正式要用的遊戲。地圖是假的測試校園，不是清大。

## 學員怎麼玩

- 在活動卡片按遊戲按鈕，會先把遊戲下載到手機（有下載進度），完成後自動進入。之後再開不用重新下載。
- 一開始整張地圖都是霧，霧會慢慢飄動（手機在背景、地圖捲出畫面、全部過關時停止，省電；手機設定「減少動態效果」時是靜態的霧）。每一關只給謎語當提示（例如「整點時它會說話，抬頭找最高的那一個」），不直接給地點。
- 找到關主、完成關卡後，關主會給密鑰。學員按遊戲裡的「📷 掃描關主 QR code」掃（不要用手機的相機 App，會跑到別的瀏覽器、要重新登入），或在遊戲頁輸入代碼（例如 `S1-WFVYVWYX`）。驗證通過後，那一關附近的霧會慢慢散開，地圖上出現地點名稱。
- 密鑰寫死在遊戲資源包裡，學員輸入時直接在手機上驗（不用網路），對了馬上解開，不會再被收回；列表顯示解開的時間。
- 同一小隊共用進度。隊友解開、或關主記錄這隊完成的關卡，其他人的手機同步時（幾分鐘內，或切回遊戲時）會自動補上；平常大部分靠手機本地，不會一直連線。
- 第 7 關是**隱藏關卡**（最後會合的地方）：時間到之前學員畫面完全看不到（不寫「終點」、不倒數、計數是 /6）。活動結束前幾分鐘（照伺服器時間）才出現在清單和地圖上（金色的點），手機跳提示，計數變成 /7。時間還沒到就先拿到第 7 關密鑰的小隊，解開後就看得到。
- 全部過關＝7 關都解開（包含隱藏關卡），才會整片霧散掉、放慶祝動畫。

## 關主（工作人員）要做什麼

1. 在工作人員端打開活動卡片，按「🎯 關主登入」（活動有設關主通行碼的話，第一次要輸入）。也可以用管理端「遊戲資源包」分頁顯示的關主連結。
2. 第一次進來先選「你負責哪一關」（一個關主顧一關，這支手機會記住）。之後畫面只要按小隊按鈕；真的要換關卡，按上面的「換關卡」。
3. 按小隊，再按「產生密鑰」，畫面會出現 QR code 和代碼。換小隊（或換關卡）時，上一隊的 QR code 會自動收起來，不會誤以為已經產生了新的。
   - 密鑰綁小隊：給第 1 小隊的碼，第 2 小隊拿去用會驗不過。
   - 防呆：產生某一隊的密鑰後，下面會問「完成了嗎？要一起標示完成並上傳分數？」，按「✓ 標示完成」等於按了過關；按「先不要」就只給密鑰。
   - 密鑰寫死在遊戲裡（關卡＋小隊＋活動算出來），沒網路也能產生。同一個資源包用在別的活動、或測試模式換一次，密鑰就不一樣。
   - 選「不限小隊」產生的碼每一隊都能用，例如當作彩蛋。
   - 同一關、同一小隊產生的碼每次都一樣，可以先印出來。
4. 這一隊過關時，在「過關」填分數（預設是活動設定的每關分數），按「✓ 過關（記錄完成＋上傳分數）」：記錄這隊完成這關，同時把分數送進團隊計分。沒網路也可以按，分數連上後自動補傳。
   - 每個活動在團隊計分裡自動有一個 Game，名稱就是活動名稱，預設立即發布。要改成「等全部隊伍到齊」或「手動發布」，到管理端「團隊計分 → Game 清單」設定。
   - 每隊每關只算一筆。同一關再按一次是改分數，不會重複加。
   - 要從活動卡片的「開始遊戲」進來才能上傳分數，因為這樣才知道是哪個活動。
5. 全部關卡都解開時，地圖上的霧會整片散掉，第一次全過會放慶祝動畫。
6. 隊員忘了輸入密鑰也沒關係：關主按了「過關」，那一隊的手機同步時（幾分鐘內）會自動解開。
7. 「產生過的密鑰」記錄每一組產生過的密鑰：給錯或還沒過關就給了，按「撤回」取消這隊這關的完成（分數改成 0）；給過但忘了按過關，按「標示完成」。按「顯示」可以再秀一次 QR code。
8. 「各小隊進度」可以看每一隊解開了哪幾關，也看得到輸入錯誤密鑰的次數。

## 活動設定（管理端「營期流程與活動 → 遊戲資源包」）

| 欄位 | 說明 |
| --- | --- |
| 活動結束時間 | 隱藏關卡（第 7 關）在這個時間之前出現 |
| 結束前幾分鐘出現隱藏關卡 | 預設 30 分鐘 |
| 密鑰鹽（keySalt） | 選填：改了之後所有密鑰都換掉（例如密鑰外流） |
| 小隊數 | 關主產生密鑰、看進度時列出幾隊，預設 8 |
| 每過一關幾分 | 關主上傳分數時的預設值，預設 100，關主可以臨場改 |

關卡、謎語和地圖目前寫在 `manifest.json` 的 `data`（stamps、map；關卡加 `"hidden": true` 就是隱藏關卡，可另外寫 `endAt`、`revealMinutesBefore` 當預設）。正式版可以改成讀清大地圖，並把關卡改成在管理端填。

## 資料怎麼存

- 分數：關主上傳的分數存在團隊計分（Game `gx<活動ID>`），每隊每關一筆，操作紀錄記得是哪位關主上傳的。
- 集章：每次解開送一筆 `{ stamp, key }` 到小隊頻道 `sq<小隊>-fog:<活動ID>`，存在營隊資料庫的「遊戲收件」分頁，只用來讓同一小隊互相補齊；密鑰在手機上驗。關主過關是 `{ stamp, key, master: 1 }`，撤回再加 `revoke: 1`（照時間，後面的蓋前面的）。
- 手機上會記一份已解開的關卡，下次打開先畫出來（斷網也看得到）；連上網同步時以伺服器為準：補上隊友和關主記錄的，伺服器上已經刪掉（例如清測試資料）或關主撤回的，手機上也會拿掉。只有斷網時自己解開、還沒送出去的會先保留，送出去後就以伺服器為準。
- 斷網時密鑰會先存在手機，連上網路後自動送出。

## 已知限制（測試版）

- 遊戲裡的掃描要允許使用相機。iPhone 第一次會問權限；如果拒絕了，要到「設定」重新允許，或改輸入代碼。
- 如果還是用手機相機 App 掃（會用別的瀏覽器打開），畫面會請學員登入，登入後自動回到遊戲並解開那一關。
- 地圖是示意圖，關卡位置用 0～1000 × 0～700 的座標表示。

## 營前測試

到管理端「營期流程與活動 → 遊戲資源包」按「🧪 開始測試模式」，就能用正式的流程試玩（密鑰、上傳分數都一樣）。測完按「結束測試並歸零」，測試期間的集章、分數全部清掉。測試中產生的關主密鑰只在那次測試有效，正式時要重新產生或重新印。
