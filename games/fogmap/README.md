# 霧之校園（測試用）

定向越野加集章的示範遊戲，用來測試遊戲資源包的整套流程，不是正式要用的遊戲。地圖是假的測試校園，不是清大。

## 學員怎麼玩

- 在活動卡片按遊戲按鈕，會先把遊戲下載到手機（有下載進度），完成後自動進入。之後再開不用重新下載。
- 一開始整張地圖都是霧。每一關只給謎語當提示（例如「整點時它會說話，抬頭找最高的那一個」），不直接給地點。
- 找到關主、完成關卡後，關主會給密鑰。學員按遊戲裡的「📷 掃描關主 QR code」掃（不要用手機的相機 App，會跑到別的瀏覽器、要重新登入），或在遊戲頁輸入代碼（例如 `S1-WFVYVWYX`）。驗證通過後，那一關附近的霧會慢慢散開，地圖上出現地點名稱。
- 輸入密鑰馬上在手機上解開（沒網路也可以），列表顯示解開的時間；連上網路時送伺服器確認，密鑰不對才收回。
- 同一小隊共用進度。隊友解開、或關主記錄這隊完成的關卡，其他人的手機同步時（幾分鐘內，或切回遊戲時）會自動補上；平常大部分靠手機本地，不會一直連線。
- 終點會在活動結束前幾分鐘自動公布（照伺服器時間倒數），讓大家不會太早擠到同一個地方。

## 關主（工作人員）要做什麼

1. 在工作人員端打開活動卡片，按「🎯 關主登入」（活動有設關主通行碼的話，第一次要輸入）。也可以用管理端「遊戲資源包」分頁顯示的關主連結。
2. 選關卡和小隊，按「產生密鑰」，畫面會出現 QR code 和代碼。
   - 密鑰綁小隊：給第 1 小隊的碼，第 2 小隊拿去用會驗不過。
   - 密鑰是事先寫好的：關主頁一打開（有網路的時候），就把每一關×每一隊的密鑰存在手機，畫面會顯示「✓ …都存在手機了」。之後到沒網路的地方，照樣可以產生 QR code 和代碼。出發前先在有網路的地方打開關主頁、看到這行再走，頁面不要關。
   - 選「不限小隊」產生的碼每一隊都能用，例如當作彩蛋。
   - 同一關、同一小隊產生的碼每次都一樣，可以先印出來。
3. 這一隊過關時，在「過關分數」填分數（預設是活動設定的每關分數），按「過關，上傳分數」，分數就會送進團隊計分。
   - 每個活動在團隊計分裡自動有一個 Game，名稱就是活動名稱，預設立即發布。要改成「等全部隊伍到齊」或「手動發布」，到管理端「團隊計分 → Game 清單」設定。
   - 每隊每關只算一筆。同一關再按一次是改分數，不會重複加。
   - 要從活動卡片的「開始遊戲」進來才能上傳分數，因為這樣才知道是哪個活動。
4. 隊員忘了輸入密鑰：選關卡和小隊，按「✓ 記錄這隊完成這關」（按「過關，上傳分數」也會一起記錄），沒網路也可以按，連上後送出。
5. 「各小隊進度」可以看每一隊解開了哪幾關，也看得到輸入錯誤密鑰的次數。

## 活動設定（管理端「營期流程與活動 → 遊戲資源包」）

| 欄位 | 說明 |
| --- | --- |
| 活動結束時間 | 終點在這個時間之前公布 |
| 結束前幾分鐘公布終點 | 預設 30 分鐘 |
| 小隊數 | 關主產生密鑰、看進度時列出幾隊，預設 8 |
| 每過一關幾分 | 關主上傳分數時的預設值，預設 100，關主可以臨場改 |

關卡、謎語和地圖目前寫在 `manifest.json` 的 `data`（stamps、finale、map）。正式版可以改成讀清大地圖，並把關卡改成在管理端填。

## 資料怎麼存

- 分數：關主上傳的分數存在團隊計分（Game `gx<活動ID>`），每隊每關一筆，操作紀錄記得是哪位關主上傳的。
- 集章：每次解開送一筆到小隊頻道 `sq<小隊>-fog:<活動ID>`，存在營隊資料庫的「遊戲收件」分頁。伺服器會用送出那個人「現在」的小隊驗證密鑰，驗過才算。
- 手機上會記一份已解開的關卡，下次打開先畫出來，等伺服器回來再更新。
- 斷網時密鑰會先存在手機，連上網路後自動送出。

## 已知限制（測試版）

- 遊戲裡的掃描要允許使用相機。iPhone 第一次會問權限；如果拒絕了，要到「設定」重新允許，或改輸入代碼。
- 如果還是用手機相機 App 掃（會用別的瀏覽器打開），畫面會請學員登入，登入後自動回到遊戲並解開那一關。
- 地圖是示意圖，關卡位置用 0～1000 × 0～700 的座標表示。

## 營前測試

到管理端「營期流程與活動 → 遊戲資源包」按「🧪 開始測試模式」，就能用正式的流程試玩（密鑰、上傳分數都一樣）。測完按「結束測試並歸零」，測試期間的集章、分數全部清掉。測試中產生的關主密鑰只在那次測試有效，正式時要重新產生或重新印。
