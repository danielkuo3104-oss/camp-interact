# 幸運刮刮樂（測試用）

賭場活動用的線上刮刮樂，用來測試「序號＋刮開＋中獎動畫＋兌獎」整套流程，不是正式版。

## 學員怎麼玩

1. 到兌換處（例如用籌碼換），關主按「🎲 隨機發一張」，畫面出現 QR code 和序號（例如 `ABCD-EFGH`）。
2. 學員在遊戲裡按「📷 掃描 QR code」掃（不要用手機的相機 App，會跑到別的瀏覽器、要重新登入），或輸入序號，按「開始刮」。
3. 出現一張刮刮樂，用手指在銀色的地方刮：刮過的地方銀漆不見、掉下刮屑、手機輕輕震動。刮掉一半以上自動全開（也可以按「直接全部刮開」）。
4. 中獎：卡片發光、獎項跳出來；頭獎、二獎全螢幕放光芒＋金幣雨。沒中：卡片搖一下、顯示「銘謝惠顧」。
5. 中獎的卡片下面有「兌獎 QR code」，拿給兌獎處掃。
6. 「我的刮刮樂」列出這支手機領過的每一張：序號、領取時間、刮開時間（到秒）、結果。點一下可以再打開。

## 關主（工作人員）要做什麼

從工作人員端活動卡片按「🎯 關主登入」進來，有四個分頁：

| 分頁 | 做什麼 |
| --- | --- |
| 🎲 發券 | 「隨機發一張」從還沒發出去、也還沒人領的序號裡隨機挑一張，顯示 QR code＋序號；「下一張」繼續發。下面列這支手機最近發的，看得到有沒有人領、刮開了沒。 |
| 🏆 兌獎 | 掃學員中獎畫面的 QR code（或輸入序號）：顯示獎項、誰先領的、什麼時候刮開；同一張被兩個人領會跳警告（只算第一個）。按「✓ 確認兌獎」，同一張不能再兌。 |
| 📊 庫存 | 每個獎項的總數／已發／已刮／已兌、重複使用的序號、最新刮開（誰、什麼獎、幾點幾分幾秒）。每 20 秒自動更新。 |
| 📋 序號表 | 整副牌：每個序號是什麼獎、狀態。「複製全部」可以貼到試算表，要印實體卡時用。**不要給學員看。** |

多支手機一起發券也不會重複：發出去的序號會送到伺服器，其他關主手機更新時（20 秒內）就會跳過。

## 測試模式

管理端「營期流程與活動 → 遊戲資源包」按「🧪 開始測試模式」：

- 整副牌重排（另一副序號），結束測試後作廢、紀錄全部歸零。
- 關主「發券」多一個「指定發哪個獎」，發出來的那張會標示是什麼獎。
- 學員畫面多一個「🧪 指定刮到哪個獎」：自己選獎項（或隨機）領一張，不用等關主，方便一個人測全部的動畫。

## 活動設定（管理端「營期流程與活動 → 遊戲資源包」）

| 欄位 | 說明 |
| --- | --- |
| 刮刮樂名稱 | 印在卡片上方，預設「幸運刮刮樂」 |
| 總共幾張 | 預設 120，最多 2000；比獎項張數加起來少就用獎項張數 |
| 獎項 | 一行一個：`名稱|張數|說明`，例如 `頭獎|1|籌碼 1000`。最多 4 種，照順序用獎盃、鑽石、籌碼、幸運草的圖。沒填用預設：頭獎 1、二獎 3、三獎 10、幸運獎 25 |
| 沒中獎顯示 | 預設「銘謝惠顧」 |
| 序號鹽 | 選填：改了之後序號和獎項全部重排（例如序號外流），要重新發 |

## 資料怎麼存

- 序號和獎項是「系統先排好」：用序號鹽＋活動範圍算出每張的序號，再用同一個種子洗牌決定獎項。同一個活動每支手機算出來都一樣，查獎項、刮開都不用網路。
- 學員領券、刮開各送一筆到 `in-scratch:<活動>`（學員之間看不到別人的，關主看得到全部）。
- 關主發券、兌獎送到 `w-scratch:<活動>`（只有工作人員看得到）。
- 學員手機記得自己領過的每一張（`host.save('cards')`），斷網也看得到；送出斷網會先存著，連上再補送。

## 已知限制（測試版）

- 序號是在手機上算的，懂程式的人有機會從資源包推出整副牌。正式用要改成由伺服器發序號（或印實體卡、改序號鹽）。
- 學員看不到別人有沒有領過同一張，所以「重複領」是在兌獎時由關主擋（只算第一個領的人）。
- 掃描要允許相機；拒絕了就改輸入序號。
