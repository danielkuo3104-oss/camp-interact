# 神域・雙陣營 RPG（測試資源包 factions）

依郭老師對 RPG 的建議做的測試版：8 個小隊分成兩個陣營，**不是正義對邪惡，而是兩種目標**。兩邊看到的歷史不一樣（勝者寫的版本 vs. 殘頁），最後由進度領先的陣營主導結局。

## 學員

- 依「陣營分配」自動分到陣營：畫面顏色、徽章、目標、讀到的歷史都不同。
- 每隊固定一個 **天賦**、一個 **弱點**（照活動＋小隊算出來，關主畫面也看得到，不用另外記）。
- **神域地圖**：神域符文疊在校園上，NPC 位置一開始是迷霧（只看得到地點名）。找到 NPC、掃他給的 QR code（或輸入密鑰）→ 迷霧散開、跳出 NPC 的自我介紹和「對你們陣營說的話」。
- **印戳手冊**：每位 NPC 一個專屬印戳，解開時蓋章動畫；集滿有慶祝。
- 密鑰綁小隊（郭老師提的防弊：A 隊拿到的 QR，B 隊偷掃也驗不過），在手機上驗，沒網路也能用。
- **兩陣營拔河**：即時顯示兩邊進度。
- **結局**：揭曉時間到（或關主按「宣布結局」），所有人全螢幕看到領先陣營的結局。

## NPC／關主

- 選「我是哪位 NPC」和「眼前是第幾隊」→ 看到那一隊的陣營、天賦弱點、密鑰／QR code、自己的台詞（自介、對該陣營的話、**玩家問不出關鍵問題時的固定台詞**）。
- 「✓ 過關」：記錄這隊遇見這位 NPC（隊員手機同步）＋上傳分數到團隊計分（斷網先存）。
- 「兩陣營進度」：每 45 秒統計各隊，寫到同步頻道給學員看拔河；「🎬 宣布結局」。

## 設定

| 欄位 | 說明 |
| --- | --- |
| 陣營分配 `teams` | `A:1,3,5,7;B:2,4,6,8` |
| 揭曉結局的時間 `endAt` | 測試模式時已經過了就只看關主手動宣布 |
| 每位 NPC 分數 | |
| 陣營、NPC、天賦弱點（JSON） | 按「填入預設再改」修改內容；NPC 的 `x`/`y` 是地圖位置（0–1000／0–700，目前是示意位置） |
