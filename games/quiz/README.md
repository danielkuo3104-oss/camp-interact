# 搶答問答（quiz，測試資源包）

全場一起玩的問答，像 Kahoot：主持人出題，所有手機同時倒數、選答案，時間到公布答案、各選項人數和小隊排名。

## 怎麼玩

- **學員**：從活動的「開始遊戲」進來，等主持人出題。題目出現後選一個答案（選了不能改）。時間到手機會顯示答對或答錯、各選項有幾個人選、目前小隊排名。
- **主持人（工作人員）**：按「開始第 1 題」，時間到會自動公布答案（也可以提早按「公布答案」），再按「下一題」。最後按「結束，公布排名」，再按「把各隊分數送進團隊計分」。
- **投影**：主持人畫面按「📺 投影畫面」，會顯示題目、倒數、已作答人數、公布後的長條圖和排名。

## 設定

| 設定 | 說明 |
| --- | --- |
| 題目 | 一行一題：`題目|選項1|選項2|選項3|選項4|答案`。選項 2～4 個，答案寫編號（1～4）或 A～D。最多 40 題。 |
| 每題作答幾秒 | 預設 20 秒 |
| 每題滿分 | 預設 100 分 |
| 越快分數越高 | 1：馬上答對滿分，最後一秒答對拿一半。0：答對就滿分（網路不好的場地建議用 0）。 |
| 出題後倒數幾秒 | 預設 8 秒，留時間讓每支手機收到題目。全場同時玩的人越多，手機收到越慢（100 人壓力測試：一半的手機 3 秒內收到、九成 9 秒內），所以 100 人左右建議 10 秒，50 人以下 5 秒就夠。 |

## 計分

- 個人：答對的分數加總，顯示在自己手機右上角。
- 小隊：每一題「隊上有作答的人」的平均得分，全部題目加起來。所以人多的隊不會佔便宜，沒作答的人不會拉低平均。
- 作答時間從「題目出現在自己手機上」開始算，晚幾秒收到題目的手機不吃虧。
- 送進團隊計分時是一筆（關卡代號 `QUIZ`），重送會更新不會重複加。

## 注意

- 正確答案寫在設定裡，手機拿得到（這樣斷網也能馬上對答案）。很懂技術的學員找得到，嚴格的比賽請改用關主人工計分。
- 主持人換手機或重新整理，進度會自動找回來。
- 斷網時作答會先存在手機，連上後補送；超過作答時間 15 秒才送到的不算。
