# 級聯封鎖・密室（測試資源包 labescape）

依 2027 活動股「密室一驗企劃書」和郭老師的建議做的測試版：**手機就是壞掉的主控 AI「阿斯克勒庇俄斯」**，關主只是 AI 的具象。

## 學員看到什麼

- 最上面是「級聯封鎖倒數」。剩 30 分鐘轉橘色、10 分鐘轉紅色（警報閃、故障字）、最後 1 分鐘每 10 秒震一下。
- AI 完整度（0–100%）：每解開一關就修復一點，AI 的臉、名字的故障效果越來越少，並說出那一關的修復台詞。
- 關卡鏈：解開的打勾，現在這一關亮起，後面的顯示「？？？」。
- 卡在同一關太久，AI 自動推送線索（每關的 `hintAfter` 分鐘，跳通知＋震動）。
- 解法：小隊自己解出的密碼（`answer`），或掃關主的 QR code／輸入關主密鑰（綁小隊，別隊拿去用驗不過）。
- 喚醒碼（關主給）：AI 清醒一下，給這一關最明顯的線索（`hints` 的最後一個）。每隊預設 3 組、各用一次。
- 全部解開：「級聯封鎖解除」全螢幕動畫＋彩帶，顯示逃出時間。
- 同一小隊共用進度（小隊頻道 `sqN-esc`），斷網也能輸入，連上後自動補送。

## 關主

- 選關卡、選小隊 → 看到這一隊這一關的密鑰和 QR code。
- 「🎭 你的角色與台詞」：這一關的角色、開關台詞、任務、所有線索（標出幾分鐘自動推送）。
- 「🔆 喚醒碼」：這一隊的喚醒碼（可以顯示 QR）。
- 「✓ 過關」：記錄這一隊完成這一關（隊員手機會同步打勾）並上傳分數到團隊計分；沒網路先存在手機，連上自動補送。
- 「各隊進度」：每隊解到第幾關、用了幾組喚醒碼、幾點逃出；逃出的隊伍可以「上傳逃出加分」（剩幾分鐘 × 每分鐘加分）。

## 設定（管理端「營期流程與活動 → 遊戲資源包」）

| 欄位 | 說明 |
| --- | --- |
| 封鎖完成時間 `endAt` | 倒數到這個時間。測試模式時日期當作今天；沒填、或測試時已經過了 → 從手機第一次打開開始「練習計時」 |
| 全長 `minutes` | 預設 150 分鐘（13:00–15:30） |
| 小隊數、每關分數、剩餘每分鐘加分、喚醒碼組數 | |
| 關卡 `stages`（JSON） | 每關 `id name role answer brief hints hintAfter restore line`；按「填入預設再改」再改內容 |
| 密鑰鹽 `keySalt` | 密鑰外流時改掉，全部密鑰和喚醒碼都會換 |

「套用預設：2027 密室一驗」會填好時間和分數。
