# 集章手冊（測試用）

像紙本集章手冊的測試遊戲：每格印章一開始是灰色輪廓，到關卡掃 QR code 或輸入序號，就會播放蓋章動畫，蓋上彩色印章並記下蓋章時間。用來測試「集章＋蓋章動畫」的流程，圖案和關卡是示範用的。

## 學員怎麼玩

- 在活動卡片按「🎮 開始遊戲」，第一次會先把遊戲（程式和 9 張圖）下載到手機，之後斷網也打得開。
- 手冊有 8 格印章（兩欄、交錯排），還沒蓋的是灰色輪廓，下面寫地點提示。
- 到關卡後按「📷 掃描印章 QR code」掃（不要用手機的相機 App，會跑到別的瀏覽器、要重新登入），或輸入序號（例如 `A1-ABCD2345`，大小寫都可以）。
- 序號對了：全畫面播放蓋章動畫（印章從上面壓下來、震一下、墨水濺開、抬起來後蓋上日期時間），點一下可以跳過。手冊上那一格變成彩色印章，旁邊有「2026.11.10 16:32」的日期章。
- 序號錯了提示「這個序號不對」；同一個章不會蓋兩次。
- 序號在手機上驗，**沒網路也能蓋**；蓋好的章存在手機，也送到伺服器（沒網路先排著，連上自動補送）。換手機、清掉瀏覽器資料，重新打開會從伺服器找回來。
- 8 個都蓋好：放彩帶、顯示「🎉 集章完成」和完成時間。
- 手機設定「減少動態效果」時，蓋章改成淡入，不跑動畫。

## 關主（工作人員）要做什麼

1. 在工作人員端打開活動卡片，按「🎯 關主登入」。
2. 「各關印章序號」列出每一關的序號，按「顯示 QR」可以給學員掃；按「🖨 列印全部 QR code」一次印出 8 張（一張一關，可以剪下來貼在關卡）。
   - 每個人拿到的是同一個序號（像關卡上的實體印章），不分小隊。
   - 序號寫在遊戲裡，沒網路也看得到。
   - 同一個資源包用在別的活動、或測試模式換一次，序號就不一樣；測試完正式前要重新印。
3. 「集章進度」看幾個人蓋過章、幾個人集滿、每一關有幾個人蓋，以及每個人蓋了哪幾個（滑過圓點看時間）。按「重新整理」更新。

## 活動設定（管理端「營期流程與活動 → 遊戲資源包」）

| 欄位 | 說明 |
| --- | --- |
| 手冊標題 | 手冊最上面的字，預設「一起集滿印章吧！」 |
| 序號鹽（keySalt） | 選填：改了之後所有序號都換掉（例如序號外流），要重新印 QR code |

印章（名稱、圖、提示）寫在 `manifest.json` 的 `data.stamps`：`{ "id": "A1", "name": "營地帳篷", "art": "tent.svg", "hint": "報到處旁邊的大帳篷" }`。id 只能用英文字母和數字。換圖的話把新的 SVG 放進資料夾、列進 `files`，並把 `version` 加一（`index.json` 也要改）。圖用彩色畫，手冊會自動把沒蓋的變成灰色輪廓。

## 資料怎麼存

- 序號 = 雜湊（序號鹽＋活動範圍＋印章 id）→ 8 個好輸入的字（沒有 0/O、1/I），和霧之校園同一套算法，不用後端。
- 蓋章送到頻道 `sb`（`host.ch('sb')`），內容 `{ stamp, key, at }`。學員只讀得到自己的，工作人員讀得到全部；收件的序號在手機上重新驗過才算。
- 同步時以伺服器為準：伺服器沒有的章會從手機拿掉，只有斷網時蓋、還沒送出去的先留著。
- 手機存檔：`got`（蓋了哪些、時間）、`allDone`（慶祝只放一次）。

## 測試模式

管理端按「🧪 開始測試模式」就能用正式流程試玩；測試中的序號跟正式不同。測完按「結束測試並歸零」，測試期間蓋的章全部清掉。工作人員按活動卡片的「🎮 開始遊戲」是試玩，資料跟正式分開。
