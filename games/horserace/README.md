# 賭場賭馬（測試資源包 horserace）

依 2027 活動股賭場企劃（賭馬劇本 8 隻、三輪）和郭老師「賭馬線上下注」的建議做的測試版。**不計分**（賭場的輸贏用玩具鈔，不進團隊計分）。

## 學員看到什麼

- 上方：第幾輪、現在狀態（下注中／停止下注／比賽中），右上角是「我的籌碼」（每人一份，`purse` 起算，自動扣押注、加贏回）。
- 下注：點一匹馬（顯示賠率）、輸入金額 → 「下注」。停止下注前可以「改押」，同一輪最後一次算數；每輪最多押 `maxBet`，也不能超過手上籌碼。
- 主持人按開跑：倒數 `countdown` 秒（給每支手機收到），手機和投影一起跑同一場比賽（名次開跑時就決定，每支手機照伺服器時間自己播，所以畫面一致）。
- 跑完立刻結算：押中第一名 → 拿回「押注 × 賠率」，彩帶＋震動；沒押中 → 晃一下。頒獎台顯示前三名。
- 下注會存在手機也送到伺服器，換手機登入找得回來；斷網時先排隊，連上補送。

## 主持人（工作人員）

1. 「開放第 1 輪下注」→「停止下注」→「🏁 開跑」→ 跑完後「下一輪」。停止後也能「重新開放下注」。
2. 每匹馬被幾人押、押了多少；跑完後列出**各隊這一輪押多少、贏回多少、淨輸贏**，給銀行換玩具鈔。
3. 「📺 投影畫面」：開新分頁（`view=show`），大字倒數、大賽道、頒獎台，接投影機用。
4. 狀態存在同步頻道 `horse:範圍`（只認工作人員寫的）並備份到 `w-horse`，重開也接得回去。

## 名次怎麼決定

- 正式：照賠率加權隨機（賠率低的熱門馬比較容易贏），在主持人按開跑時決定。
- 測試模式：填了「預設名次」（例如 `3,1,5,2,4,6,7,8`）就照它跑，方便彩排和測試結算。

## 設定

| 欄位 | 說明 |
| --- | --- |
| 馬匹 `horses` | 一行一匹：`名字|賠率`，最多 12 匹 |
| 每人籌碼 `purse`、每輪上限 `maxBet`、輪數 `rounds` | |
| 開跑倒數 `countdown`、比賽秒數 `raceSeconds` | 倒數至少 3 秒，網路慢的場地可以拉長 |
| 預設名次 `preset` | 只在測試模式用 |

## 注意

- 賠率要和實體賭場一致；名次照賠率加權抽，所以押任何一匹的期望值都是 1 ÷（所有馬 1/賠率 的總和）；預設 8 匹約 0.6 倍，莊家穩賺、學員不會穩賺（企劃書的樂透期望值 1.7 倍要修）。
- 學員押的是手機上的虛擬籌碼；要換玩具鈔請看主持人畫面的「各隊這一輪」。
